Jelaskan perbedaan antara String dan &str di Rust?
L
Lumen
deepseek-v4-pro · reasoning
Perbedaan utama antara String dan &str:
FiturString&str
OwnershipDimiliki (heap)Pinjaman (borrowed)
MutabelYaTidak
UkuranDinamisTetap (compile-time)
Kapan pakaiPerlu modify/buat baruCuma baca
Rust Salin 
// String — owned, bisa dimodifikasi
let mut s = String::from("hello");
s.push_str(" world");

// &str — borrowed reference, read-only
let greeting: &str = "hi there";
println!("{}", greeting);
Rule of thumb: pakai &str untuk parameter fungsi (lebih fleksibel), pakai String kalau perlu ownership atau modifikasi.
