Tolong buatkan fungsi validasi email di TypeScript yang support international domain
✦ Lumen
Berikut fungsi validasi email yang mendukung international domain (IDN):
function isValidEmail(email: string): boolean { const re = /^[^\s@]+@[^\s@]+\.[^\s@]+$/; if (!re.test(email)) return false; // Punycode encode IDN domains const domain = email.split('@')[1]; return domain.length <= 253; }
Fungsi ini menggunakan regex dasar dan validasi panjang domain sesuai RFC 5321. Untuk IDN seperti müller@例え.jp, pastikan browser/runtime mendukung Punycode.
Bisa kasih contoh penggunaannya?
✦ Lumen
Tentu! Berikut contoh penggunaannya:
// Standard email isValidEmail("user@example.com"); // true // International domain isValidEmail("user@münchen.de"); // true // Invalid isValidEmail("not-an-email"); // false
Kamu bisa menambahkan library seperti validator.js untuk validasi yang lebih ketat.
