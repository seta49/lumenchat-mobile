Lumen Chat — 5 Design Concepts

Mockup desain bagian chat dengan berbagai pendekatan visual. Klik "Open Full" untuk melihat versi fullscreen di tab baru.

Design A

Glassmorphism
Glassmorphism Bubbles — Efek kaca transparan dengan backdrop blur.
  • Bubble user & AI pakai backdrop-filter: blur()
  • Gradient avatar + pulse dot status
  • Code block dengan syntax highlighting warna-warni
  • Composer pill dengan gradient send button
  • Thinking indicator dengan animasi dot

Design B

Telegram Clean
Telegram-inspired Clean — Palet dark blue ala Telegram, bersih dan fungsional.
  • Warna teal-blue (#0e1621) sebagai base background
  • User bubble biru gelap (#2b5278), AI bubble lebih gelap
  • Timestamp inline di setiap bubble (ala Telegram)
  • Code block dengan header "Salin" dan language tag
  • Composer dengan ikon emoji & attach ala Telegram
↗ Open Full

Design C

Split Cards
Split Persona Cards — User = teks biasa, AI = kartu beraksen.
  • User messages tanpa bubble, hanya teks rata kanan
  • AI messages dalam card dengan left accent stripe
  • Card header: avatar + nama model + label reasoning
  • Tabel native di dalam card untuk perbandingan
  • Token badge di bawah setiap respons AI
  • Skeleton shimmer loader saat thinking
↗ Open Full

Design D

iMessage Flow
iMessage Bubble Flow — Familiar iOS chat experience, clean dan native.
  • User bubble biru terang (#0a84ff) ala iMessage
  • AI bubble abu gelap (#262628) seperti received messages
  • Read receipt "Dibaca" di bawah pesan user
  • Link pill clickable untuk dokumentasi
  • iOS-style typing indicator (3 bouncing dots)
  • Quick action bar di bawah composer
↗ Open Full

Design E

Gemini Ambient
Gemini Ambient — Inspirasi Google Gemini, spacious dan elegan.
  • Logo sparkle dengan 4 dots berputar (animated)
  • Model selector floating pill di atas chat
  • User message tanpa bubble, AI full-width typography
  • Section titles dengan ikon untuk organisasi konten
  • Code block dengan toolbar (Copy + Apply)
  • Gemini-style shimmer thinking indicator
  • Composer wide dengan bottom tools row
