Halo Lumen! Bisa bantu saya belajar Rust ownership model? 10:30 ✓✓
Tentu! 🦀 Rust punya konsep unik bernama ownership yang jadi fondasi memory safety-nya. Tiga aturan utama:

1️⃣ Setiap value punya satu owner
2️⃣ Hanya ada satu owner di satu waktu
3️⃣ Kalau owner keluar scope, value di-drop 10:31
Kasih contoh kode sederhananya dong! 10:32 ✓✓
Ini contoh dasar ownership & move:
Rust Salin
fn main() { let s1 = String::from("hello"); let s2 = s1; // s1 dipindah ke s2 // println!("{}", s1); // ERROR! println!("{}", s2); // OK ✅ }
Setelah let s2 = s1, variabel s1 tidak valid lagi — ownership-nya sudah move ke s2. Ini beda dari bahasa lain yang pakai reference counting atau GC. 10:33
Menarik! Gimana kalau mau tetap pakai s1?
Kamu bisa pakai .clone() untuk membuat deep copy:
Rust Salin
fn main() { let s1 = String::from("hello"); let s2 = s1.clone(); // deep copy! println!("{} {}", s1, s2); // OK ✅✅ }
Atau pakai borrowing (&) kalau cuma perlu baca tanpa ambil alih:
Rust Salin
fn print_len(s: &String) { println!("Panjang: {}", s.len()); } // s masih valid setelah dipinjam!
