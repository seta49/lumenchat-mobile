Jelaskan konsep React Server Components dan gimana bedanya dengan Client Components?
⚡ React Server Components (RSC)
Server Components adalah komponen yang render di server dan mengirim HTML ke client. Mereka:

• Tidak punya akses ke hooks (useState, useEffect)
• Bisa langsung async/await — fetch data tanpa useEffect
• Bundle size lebih kecil karena kode tidak dikirim ke client
• Bisa import modul berat (ORM, markdown) tanpa bloat
🖥️ Client Components
Client Components (ditandai 'use client') berjalan di browser:

• Punya akses penuh ke hooks dan state
• Bisa handle interaksi user (click, input, gesture)
• Cocok untuk UI yang interaktif (form, modal, animasi)
TypeScript
📋 Copy ↗ Apply 
// app/page.tsx — Server Component (default)
async function Page() {
  const posts = await fetch('/api/posts');
  return <PostList data={posts} />;
}

// components/LikeButton.tsx — Client Component
'use client';
function LikeButton() {
  const [liked, setLiked] = useState(false);
  return (
    <button onClick={() => setLiked(!liked)}>
      {liked ? '❤️' : '🤍'}
    </button>
  );
}

Rule of thumb: mulai dari Server Component, baru pindah ke Client kalau butuh interaktivitas. Ini meminimalkan JavaScript yang dikirim ke browser.
