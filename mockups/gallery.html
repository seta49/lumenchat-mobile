Version A

Minimal Zen
Inspired by: iMessage + Gemini
  • Header super minimal — avatar, model name, 2 tombol
  • AI response full-width, no bubble, subtle left accent on hover
  • Action buttons (copy/regenerate/edit) muncul on hover
  • Composer floating pill, clean tanpa chip reasoning
  • Paling sedikit chrome — fokus ke konten

Card Tabs
Inspired by: Claude + Perplexity

  • Horizontal model chip strip — switch model cepat
  • AI response dalam card dengan header (avatar + stats) & footer (actions)
  • Quick suggestion chips di bawah AI response
  • Composer dengan meta info (reasoning + model)

Version C

Telegram Flow
Inspired by: Telegram + Discord
  • Header ala Telegram — nama + status (model + online indicator)
  • Chat bubbles: user = biru gelap, AI = abu gelap dengan avatar
  • Timestamp + read receipts per message
  • Inline action bar (copy/retry/edit/delete) di bawah AI bubble
  • Composer dengan emoji button + model/reasoning badges
  • Typing indicator animasi (3 bouncing dots)
