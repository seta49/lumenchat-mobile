Oke, ini implementasi merge sort di Python: def merge_sort(arr): if len(arr) <= 1: return arr mid = len(arr) // 2 left = merge_sort(arr[:mid]) right = merge_sort(arr[mid:]) return merge(left, right) def merge(left, right): result = [] i = j = 0 while i < len(left) and j < len(right): if left[i] <= right[j]: result.append(left[i]) i += 1 else: result.append(right[j]) j += 1 result.extend(left[i:]) result.extend(right[j:]) return result Cara kerjanya: array dipecah jadi 2 bagian secara rekursif sampai tiap bagian cuma punya 1 elemen, terus di-merge balik secara terurut. Time complexity-nya O(n log n) di semua kasus.
