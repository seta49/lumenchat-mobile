Oke! Ini contoh tombol dengan scale animation pakai Reanimated:
import Animated, { useSharedValue, useAnimatedStyle, withSpring, } from 'react-native-reanimated'; import { Pressable } from 'react-native'; function ScaleButton({ children }) { const scale = useSharedValue(1); const style = useAnimatedStyle(() => ({ transform: [{ scale: scale.value }], })); return ( <Pressable onPressIn={() => (scale.value = withSpring(0.92))} onPressOut={() => (scale.value = withSpring(1))} > <Animated.View style={style}> {children} </Animated.View> </Pressable> ); }
Efeknya: tombol mengecil ke 92% saat ditekan, lalu spring kembali ke 100% saat dilepas. Animasinya berjalan di UI thread jadi 60fps smooth! ✨
